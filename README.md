# E-Commerce Delivery & Operations Intelligence

## Project Overview

E-Commerce Delivery & Operations Intelligence is an end-to-end data analytics project focused on understanding e-commerce sales, delivery performance, cancellations, returns, and product performance.

The project uses a common e-commerce dataset to perform analysis with Excel, SQL, Python, and Power BI.

## Tools & Technologies

- **Excel:** Data analysis, pivot tables, and reporting
- **SQL (MySQL):** Data querying, filtering, joins, grouping, and subqueries
- **Python:** Data analysis using Pandas and NumPy
- **Power BI:** Interactive dashboards, KPI cards, charts, and business insights

## Project Objectives

- Analyze overall orders and revenue.
- Evaluate delivery performance and delivery partners.
- Understand order cancellations and product returns.
- Identify top-performing product categories and products.
- Compare revenue and orders across sales channels.
- Present key business metrics through interactive Power BI dashboards.

## Project Dashboard

The Power BI report contains four pages:

1. **Executive Overview** – Overall orders, revenue, order status, and regional performance.
2. **Delivery Performance** – Delivery partners, delivery success, and regional delivery analysis.
3. **Cancellations & Returns** – Cancelled orders, returned orders, rates, and reasons.
4. **Product & Business Analysis** – Product revenue, top products, average order value, and sales channels.

The exported Power BI dashboard PDF is included in this repository.

## Project Files

- `ecommerce.csv` – Dataset
- Python notebook – Data analysis and exploration
- SQL file – SQL queries and analysis
- Excel workbook – Excel analysis
- Power BI PDF – Four-page dashboard report

## Key Business Questions

- How much revenue does the business generate?
- Which regions contribute the most revenue?
- Which delivery partners handle the most orders?
- What are the cancellation and return rates?
- Which products and categories generate the highest revenue?
- Which sales channels contribute the most orders and revenue?

## Conclusion

This project demonstrates the use of Excel, SQL, Python, and Power BI in an end-to-end data analytics workflow, from working with a dataset to presenting business metrics in a dashboard.
